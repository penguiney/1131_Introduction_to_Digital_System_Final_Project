## 猜拳老虎機 — 數位系統實驗期末專案

以 Verilog 實作、運行於 FPGA 開發板的雙人猜拳對戰遊戲。雙方透過按鈕暫停快速切換的猜拳圖案來決定出拳，並以七段顯示器與點陣顯示器呈現分數與遊戲狀態。

### 遊戲玩法

#### 基本規則

雙人遊玩，雙方各使用一邊的顯示器和按鈕，遊戲開始後，DOT MATRIX 會以固定頻率快速切換石頭、剪刀、布圖案，按下暫停鍵（左方 KEYPAD 0、右方 KEYPAD 7）會停止切換，決定自己出的拳，能出到什麼拳取決於玩家的手速與眼力。

#### 計分

- 一局為 10 輪制，每輪又採 10 分制
- 回合勝利的一方，得 1 分，先得 10 分的一方贏得該輪，先拿下 10 輪的玩家獲勝
- 兩側七段顯示器會分別顯示雙方的分數，中間顯示輪數            (分數 --- 輪數 - 輪數 --- 分數)

#### 畫面顯示（DOT MATRIX）

- 石頭、剪刀、布：克制關係為 石頭 > 剪刀 > 布 > 石頭
- 笑臉：該玩家贏得一回合或平手，平手時雙方都會顯示笑臉
- 獎杯：該玩家贏得一局
- 打叉：遊戲重置

#### 操作按鍵

- KEYPAD 0：左方玩家暫停鍵
- KEYPAD 7：右方玩家暫停鍵
- KEY 0：遊戲開機鍵 / 重置鍵（所有分數歸零，回到最初狀態）

### 系統架構

整體遊戲以四種狀態（STATUS）驅動狀態機，透過 `setStatus` 模組控制各狀態間的切換：

| 狀態 | 名稱 | 說明 |
|------|------|------|
| STATUS 0 | 重置遊戲 | 重設所有分數、DOT MATRIX 顯示打叉 |
| STATUS 1 | 轉輪盤 | DOT MATRIX 快速切換猜拳圖案，等待雙方按下暫停鍵 |
| STATUS 2 | 回合結算 | 雙方皆暫停後，判定回合勝負、更新分數，結束後回到 STATUS 1 |
| STATUS 3 | 遊戲結算 | 任一方回合分數達 10 分時觸發，更新局數分數、重置回合分數，結束後回到 STATUS 1 |

#### 各狀態對應功能與模組

**STATUS 0（重置遊戲）**
- 重設所有分數
- DOT MATRIX 顯示打叉

**STATUS 1（轉輪盤）**
- `BTN_CONTROL`：偵測暫停按鈕是否被按下
- `RPS_CHANGE`：以各自獨立的 CLK_DIV 控制雙方猜拳圖案切換頻率，透過 2 bit 變數控制石頭／剪刀／布持續循環切換，並等待 STOP_SPINNING 訊號
- `DOT_CONTROL`：依據 `RPS_CHANGE` 的輸出控制 DOT MATRIX 顯示內容

**STATUS 2（回合結算）**
- `WHO_WIN`：依據 `RPS_CHANGE` 輸出的雙方出拳結果判斷勝負，輸出 `WHO_WIN_THE_ROUND`
- `COUNT_CONTROLLER`：依據 `WHO_WIN_THE_ROUND` 更新雙方回合分數
- `SEVEN_DISPLAY`：持續更新分數顯示
- `DOT_CONTROL`：勝方顯示笑臉，平手時同樣顯示笑臉

**STATUS 3（遊戲結算）**
- `COUNT_CONTROLLER`：持續判斷回合分數是否達 10 分，判定局數勝負並輸出 `WHO_WIN_THE_GAME`，觸發狀態由 STATUS 2 切換至 STATUS 3，更新局數分數並重置回合分數
- `SEVEN_DISPLAY`：持續更新分數顯示
- `DOT_CONTROL`：勝方顯示獎杯

### 模組說明（原始碼對應）

| 檔案 | 說明 |
|------|------|
| `FinalProject_group_1.v` | 頂層模組（Top Module），連接所有子模組並管理各時脈訊號 |
| `btn_control.v` | 偵測左右兩側暫停按鈕是否被按下 |
| `stop_button.v` | 處理暫停按鈕觸發後的停止訊號 |
| `rps_change.v` | 控制石頭／剪刀／布圖案的循環切換與各自的切換頻率 |
| `dot_control.v` | 控制 DOT MATRIX 顯示內容（剪刀石頭布、笑臉、獎杯、打叉） |
| `whowin.v` | 判斷回合與整局的勝負 |
| `CountController.v` | 管理並更新雙方的回合分數與局數分數 |
| `SevenDisplay.v` | 控制七段顯示器顯示回合分數與局數分數 |
| `setStatus.v` | 控制四種遊戲狀態（STATUS 0–3）之間的切換 |
